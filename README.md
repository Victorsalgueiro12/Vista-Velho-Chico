# Vista Velho-Chico — E-commerce de Moda

Desenvolvimento de uma aplicação web de comércio eletrônico voltada à comercialização de roupas e acessórios, com identidade visual inspirada na cultura nordestina e na região do Velho Chico.

O projeto foi desenvolvido com **HTML5, CSS3 e JavaScript puro**, implementando uma interface responsiva, catálogo de produtos e fluxo de pedidos com integração ao WhatsApp.

### Funcionalidades implementadas

- **Catálogo de produtos:** organização e apresentação de produtos por categorias.
- **Carrinho de compras:** gerenciamento dos itens selecionados para compra.
- **Gestão de pedidos no front-end:** consolidação dos produtos, quantidades e valores selecionados pelo usuário.
- **Integração com WhatsApp:** geração automática de uma mensagem contendo os detalhes do pedido e redirecionamento para o WhatsApp, facilitando a comunicação com o vendedor.
- **Interface responsiva:** adaptação da experiência de navegação a diferentes tamanhos de tela.
- **Identidade visual personalizada:** layout desenvolvido para representar a marca e proporcionar uma experiência de navegação intuitiva.

### Tecnologias utilizadas

- **HTML5:** estruturação semântica do conteúdo.
- **CSS3:** estilização, layout e responsividade.
- **JavaScript:** manipulação dinâmica dos produtos, lógica do carrinho e composição automática dos pedidos.
- **WhatsApp URL API:** direcionamento para o WhatsApp com a mensagem do pedido previamente preenchida.
- **Netlify:** hospedagem e publicação da aplicação web.

### Objetivo do projeto

Aplicar conceitos de desenvolvimento front-end na construção de uma solução de comércio eletrônico funcional, integrando interface, manipulação de dados no navegador e comunicação com um canal externo para facilitar o processo de solicitação de pedidos.
